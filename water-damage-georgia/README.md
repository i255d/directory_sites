# Georgia water damage leads

Gwinnett-first request site for homeowners searching water damage in Dacula, Lawrenceville, and nearby cities. Domain target: `GeorgiaWaterDamageHelp.com`.

Do not buy the domain until a restoration shop agrees to take the leads.

## Folder layout

| Folder | Purpose |
|--------|---------|
| `repos/georgiawaterdamagehelp/` | Website code (Astro). This is the Git repository. |
| `research/` | Keywords, vendors, URL pick, $300 math |

Notes stay outside `repos/` so a future GitHub repo is only the site.

## Run the site

```bash
cd repos/georgiawaterdamagehelp
npm install
npm run dev
```

Open `http://localhost:4321/`.

Plan and call list: [research/water-damage-georgia.md](research/water-damage-georgia.md).
