# One month of Ahrefs Lite ($129): how to find directory niches

Buy this for **keyword difficulty + volume + who already ranks**, not for “sites with 30K–100K visits.” That last job is Similarweb (use the trial first; cancel by Oct 16).

Lite includes Keywords Explorer, Site Explorer, and CSV export. It does **not** include Content Explorer or Batch Analysis (those are Standard). Do not scrape Ahrefs. Use **Export**.

## Week 1 — score directory phrases

**Keywords Explorer → Matching terms** (or paste the seed list below).

Filters to set:
- Country: United States
- Volume: minimum 1,000 (or 500 if the list is thin)
- Keyword Difficulty: **0–20** (easy, like our water-damage and hoop phrases)
- Include any of the patterns in “Besides near me” below (run them as separate searches; one Include box is easier than a giant OR)
- Word count: 3+ (drops one-word brands)

Sort by volume. Export the table.

**What a keeper looks like:** volume 1K–50K, KD under 20, and the top 10 is small sites or Maps — not only Yelp / Angi / Wikipedia.

## Besides “near me”

“Near me” is Google’s default for phones. Other patterns often have **less Maps competition** and still work for a directory.

| Pattern | Example | Why it matters |
|---|---|---|
| **in [city] / [city] [thing]** | basketball courts dacula, water damage atlanta | Same intent, often weaker results |
| **[county] / [state]** | gwinnett parks, georgia gutters | Your storm/roof model |
| **finder / directory / map / list of** | dump station finder, thrift store directory | People who want a list, not one pin |
| **by year / by state / by VIN** | oscar nominees 1998, towing by VIN | Programmatic. Easy to build, hard to win (we parked these) |
| **open now / free / with lights / with pool** | courts with lights, vrbo with boat | Filters Maps is bad at |
| **best [x] [city]** | best fishing charter cape coral | Review-style; more competition |
| **vs** | cape coral vs panama city | First-person guides |
| **how much / cost / prices** | fishing charter prices, water damage cost | High intent, can be a lead page |
| **for [who]** | parks with kids, dog friendly courts | Extra page per park |
| **where can I / can you** | can you fish in cape coral canals | Questions report in Ahrefs |
| **near [place]** | halal atlanta airport, imax lawrenceville | Landmark, not “near me” |

**In Ahrefs, run these as separate Matching-term searches** (do not put them all in one Include box):

```
near me
in atlanta
in georgia
gwinnett
directory
finder
list of
open now
with lights
free
by year
by state
```

Then export each and keep the same rule: volume 1K+, KD 0–20, weak independent site in the top 10.

## Week 2 — who already has the traffic

For each of the top ~15 phrases, open **Site Explorer** on the independent site in the top 10 (not Yelp).

Export **Top pages**. Write down:
- Ahrefs organic traffic (monthly)
- How many pages
- Whether the pages look thin (like Dacula’s street-name courts)

Keep niches where a weak site already gets traffic. That is the bounty.

## Week 3 — decide, then cancel

Score 8–12 niches in a sheet: volume, KD, best independent competitor’s traffic, can you add first-hand notes (Gwinnett parks, Cape Coral, storms).

Pick **one** ad-directory (likely parks/hoops) and keep the **lead** sites (storm/water/gutters). Cancel Ahrefs so month 2 does not auto-bill.

## What this will not do

- It will not list “all directories with 30K visits.” You still start from seeds or from a competitor domain.
- Ahrefs traffic numbers run **low** on long-tail sites (towing proved that). Use them to **rank ideas**, then confirm winners in Similarweb.
- $129 does not replace walking the Gwinnett parks. It tells you which other “near me” piles are as easy as basketball courts.
